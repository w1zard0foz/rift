# Ceiling Cosmos Portal

A self-contained browser projection designed for a ceiling-mounted image. Everything outside the irregular cosmic rift is true black, so the projector boundary disappears in a dark room.

## Use

Open `index.html` in a browser, press **F** for fullscreen, and press **H** to show the calibration panel. Use the sliders or arrow keys to place the portal in the ceiling corner. Settings are remembered in the browser.

- **H**: show/hide controls
- **F**: fullscreen
- **C**: cycle through corners
- **Arrow keys**: fine positioning
- **Shift + Arrow keys**: faster positioning

No images, video files, libraries, account, or internet connection are required after the page loads.
